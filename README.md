# beans-r-us.com
ENG: An educational replica of the Beans'R'Us website, based on the *Head First HTML and CSS* book. It features automatic dynamic pricing to help students test their code and web scraping scripts.

PT-BR: Réplica educacional do site Beans'R'Us para o livro 'Use a Cabeça! HTML e CSS' (Head First). Feito com preço dinâmico automático para ajudar estudantes a testarem seus códigos e scripts de web scraping.
